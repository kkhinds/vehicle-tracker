Installer fixes.

- The desktop shortcut is recreated on every install and update, not just the first one. If it went missing — or you were updating from an older version — it comes back pointing at the current app.
- Windows caches shortcut and taskbar icons per file path. An update writes a new app to the same path, so the old artwork stuck around. The installer now tells the shell to reload its icon cache, so the new icon shows up straight after installing instead of after a reboot.

## Install

Download `Vehicle-Tracker-Setup-3.2.1.exe` and run it. Existing installs update themselves a few seconds after launch and install on quit.
