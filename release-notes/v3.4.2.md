The pump price now updates every time you open the app.

It used to only check once a week, so the national price the log form compares your fill-up against could be days out of date. It checks on every launch now. If the check fails or you're offline, the last price it fetched stays put — the comparison is at worst a bit behind, never missing.

If a check finishes while you already have a fill-up open, the line updates on its own.

## Install

Download `Vehicle-Tracker-Setup-3.4.2.exe` and run it. Existing installs update themselves a few seconds after launch and install on quit.
